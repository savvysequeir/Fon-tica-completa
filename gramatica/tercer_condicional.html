Gramática: Tercer Condicional

If + had + past participle, would have + past participle

Identificación del estudiante

Explicación

If + sujeto + had + participio pasado, sujeto + would have + participio pasado.

Ejemplo: If I had studied, I would have passed. (Si hubiera estudiado, habría aprobado).

Se usa para imaginar resultados diferentes en situaciones que ya ocurrieron en el pasado.
