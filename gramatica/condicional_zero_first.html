IDEA CLAVE

Una oración condicional tiene dos partes

Condition (condición): normalmente contiene if y expresa la situación que debe cumplirse.
Result (resultado): expresa lo que ocurre, ocurre normalmente o puede ocurrir como consecuencia.

If + CONDITION, RESULT

If I study, I learn more.
Condition = If I study · Result = I learn more

El resultado no tiene que ir siempre después. Las dos partes pueden cambiar de posición sin cambiar la relación lógica:

If I study, I learn more. ↔ I learn more if I study.
ZERO CONDITIONAL

Hechos, hábitos y resultados generales

Se usa cuando una condición produce normalmente el mismo resultado: hechos científicos, rutinas, instrucciones y situaciones generalmente verdaderas.

If + Present Simple, Present Simple

Positive: If you heat water, it boils.
Negative: If I don't sleep, I feel tired.
Question: What happens if you press this button?

También puede aparecer un modal cuando expresa una regla, capacidad u obligación general: If you want to enter, you must show your ID.

FIRST CONDITIONAL

Posibilidades reales en el futuro

Se usa para una condición posible o probable y su consecuencia futura.

If + Present Simple, will + base verb

Positive: If I finish, I will call you.
Negative: If she doesn't study, she won't pass.
Question: What will you do if it rains?

En el resultado también pueden usarse can, may, might, must o un imperativo según el significado.

ORDEN Y COMAS

¿Cuándo se usa la coma?

1. Si la cláusula con IF va primero, usamos coma:

If + condition, result.
If it rains, we will stay home.

2. Si el resultado va primero, normalmente NO usamos coma:

Result + if + condition.
We will stay home if it rains.

La coma marca la separación cuando la condición introducida por if abre la oración. No cambia el significado del condicional.

ZERO CONDITIONAL · POSICIÓN

El resultado puede ir primero o después

If + present, present.
Present + if + present.

If I drink coffee at night, I can't sleep.
I can't sleep if I drink coffee at night.

En ambos casos hablamos de una consecuencia habitual o general.

FIRST CONDITIONAL · POSICIÓN

La misma movilidad es posible

If + present, will/modal + base verb.
Will/modal + base verb + if + present.

If I finish early, I will call you.
I will call you if I finish early.

Aunque hablamos del futuro, después de if normalmente usamos present simple, no will.

MODALES

¿Dónde se colocan can, may, might y must?

IF no exige un modal. If introduce la condición. En la enseñanza básica del First Conditional solemos resumir la cláusula condicional como if + Present Simple, pero conviene distinguir dos sistemas: los tiempos verbales y los auxiliares modales.

Can, may, must y might son auxiliares modales; no son formas del Present Simple. Sin embargo, algunos pueden expresar modalidad con referencia presente o futura dentro de una cláusula con if: If you can come tomorrow, call me. / If I may ask a question, ... / If you must leave early, tell me.

Might se relaciona históricamente y en ciertos usos de estilo indirecto con may, pero en el inglés actual no debe enseñarse simplemente como “el pasado de may”. También expresa posibilidad presente o futura: It might rain tomorrow. Por eso, el tiempo de referencia se determina por el contexto, no únicamente por la forma del modal.

En la cláusula de resultado del First Conditional también pueden aparecer will, can, may, might, must o un imperativo, dependiendo de si el hablante expresa consecuencia, posibilidad, permiso/capacidad, obligación o instrucción.

FormaIdeaEjemplo
will + verboresultado futuro esperadoIf I finish, I will call you.
can + verboposibilidad/capacidad u opción disponibleIf you arrive early, you can talk to her.
may + verboposibilidadIf it rains, we may stay home.
might + verboposibilidad más inciertaIf traffic is heavy, we might arrive late.
must + verboobligación/necesidadIf you want to enter, you must show your ID.
imperativeorden, consejo o instrucciónIf you see Ana, call me.

Importante: un modal también puede aparecer dentro de la cláusula con if cuando su propio significado pertenece a la condición: If you can come tomorrow, call me. Aquí can significa “si puedes venir”. Por tanto, no existe una regla que diga que los modales solo pueden aparecer en el resultado.

¿EL MODAL ESTÁ EN FUTURO?

El futuro se reconoce por el significado y el contexto, no solo por la forma del modal

Los modales ingleses como can, may, might y must no cambian de forma para marcar futuro. El contexto puede darles referencia futura.

If you finish tomorrow, you can leave early.
If it rains tonight, we may stay home.
If she calls later, I might answer.

tomorrow, tonight, later y la situación comunicativa muestran que el resultado se refiere al futuro. En cambio, will marca explícitamente una referencia futura típica del First Conditional.

Compara: If I drink coffee at night, I can't sleep = hábito/generalidad (Zero). If I drink coffee tonight, I may not sleep = posibilidad futura concreta (First).

NEGATIVAS E INTERROGATIVAS

La negación o la pregunta no cambia la lógica del condicional

Zero: If I don't sleep, I feel tired.
Zero question: Do you feel tired if you don't sleep?

First: If she doesn't study, she won't pass.
First question: What will you do if you fail?

En preguntas, la estructura interrogativa pertenece a la cláusula principal: What will you do + if you fail?

REGLA PRÁCTICA

Cómo decidir cuál usar

Pregunta 1: ¿Estoy diciendo lo que ocurre normalmente, una regla, hábito o hecho general? → Zero Conditional.

Pregunta 2: ¿Estoy hablando de una situación real/posible y de lo que ocurrirá o podría ocurrir después? → First Conditional.

Pregunta 3: ¿Hay un modal? No decidas solo por el modal. Mira el significado, el contexto temporal y la relación condición → resultado.

Regla central: normalmente no usamos will en la cláusula con if para expresar una condición futura ordinaria: ✓ If it rains, we will stay home. No: ✗ If it will rain, we will stay home.
